# DataPulse — Business Intelligence Platform

An AI-powered ad-hoc analytics bot built with Streamlit + Groq (LLaMA 3.1).

## 🚀 Live App
👉 [Open DataPulse](https://datapulsebi-aq2a586vp3h5nxc72fd8ll.streamlit.app/)

## Features
- **Data Pull** — Ask business questions in plain English, get SQL results instantly
- **Root Cause Analysis** — Understand why metrics are up or down
- **File Analysis** — Upload CSV/Excel and get instant AI insights
- **Follow-up Chat** — Continue the conversation after any analysis

## Tech Stack
- Streamlit
- Groq API (LLaMA 3.1)
- SQLite (Superstore dataset)
- Plotly
- Pandas

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
